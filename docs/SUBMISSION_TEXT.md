## What did you build? (exact text, from the project document §C6)

> An evidence-first research agent for freelancers and students. It plans search queries with an open model on Nebius Token Factory, gathers live evidence with Tavily, filters and deduplicates sources, and writes a short answer where every claim carries a verifiable citation. A code-level check removes citations that do not exist, conflicts and gaps are stated explicitly, and when evidence is insufficient the agent refuses instead of guessing. Includes tests, a research trace, and a README that lets judges reproduce it.
